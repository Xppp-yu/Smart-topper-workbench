# PoPu二维压力热力图说明

## 图表问题

一条真实 PoPu Tactilus snapshot 的原始传感值，在 64 行 × 27 列传感矩阵上怎样分布？

## 图表形式

- 类型：二维热力图；
- 渲染：Matplotlib静态PNG；
- 数据粒度：一个snapshot对应一张图；
- 矩阵方向：数组形状固定写作 `(rows=64, columns=27)`；
- 横轴：传感器列；
- 纵轴：传感器行；
- 颜色：原始数据集数值，使用感知均匀的 `magma` 色图；
- 插值：`nearest`，不进行平滑，不制造原始传感点之间不存在的细节。

## 单图与总览

- 单图根据当前帧的最小值和最大值建立色标，适合观察该帧内部空间分布。
- 五姿态总览使用共同色标，适合比较同一受试者的原始强度和空间形态。
- `empty` 不做单独归一化，因此不会把微小空床噪声人为放大到人体压力的颜色范围。

## 解释边界

- 颜色条写作 `Raw sensor value (dataset units)`，不把未标定数值称为牛顿、千克或真实压力。
- 热力图只证明JSON中的一维readings已按数据声明恢复为二维矩阵。
- 单张热力图不证明姿态算法准确，也不证明身体部位、硬件密度、气囊控制或产品效果。
